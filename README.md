# 🎨 Fun Drawing

A colorful drawing board that runs in the browser. Draw, color, add stickers and save your art as PNG.

## Features
- Draw with mouse or touchscreen; brush sizes; pen, pencil, marker, highlighter, eraser
- Color picker, color swatches, random color palette, background color
- Fill bucket, shapes (line, square, circle, triangle, star, heart, diamond), text
- Undo/Redo (Ctrl+Z / Ctrl+Y), Clear, New Drawing, Save as PNG
- Fun Tools: stickers, rainbow brush, stamps, random shape, color palette, magic brush
- Drawing Challenge with the "Give Me an Idea!" button

## Technology
HTML5 Canvas, CSS3, vanilla JavaScript. No server needed.

## Run locally
Open `index.html` in your browser.

## Deploy to GitHub Pages
1. Create a GitHub repository and upload all files.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
4. Your site will be live at `https://USERNAME.github.io/REPOSITORY/`.
